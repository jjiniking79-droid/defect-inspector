# 불량 이미지 자동 판정 프로그램 (Defect Inspector)

작업자가 정의한 불량 유형과, 라벨링한 이미지를 스스로 학습한 AI 모델을 기반으로
불량 이미지를 자동 판정하는 로컬 PC용 프로그램입니다.

---

## 1. 먼저 알아두실 점 (중요)

1. 저는 지금 Windows가 아닌 리눅스 환경에서 작업하고 있어서, 여기서 바로
   `.exe` 파일을 만들어 드릴 수는 없습니다. 대신 **내 PC에 Python을 전혀 설치하지 않고도**
   exe를 만들 수 있는 방법을 아래 "2. EXE 만들기 (Python 설치 없이)"에 준비했습니다.
   GitHub이라는 무료 웹사이트가 내 PC 대신 exe를 빌드해주고, 완성된 파일을 다운로드만
   하면 됩니다. (컴퓨터에 아무것도 설치하지 않습니다)

2. **"작성자가 텍스트로 적은 불량 유형 정의"는 참고 문서로 저장/보관**됩니다.
   자유롭게 쓰신 문장(예: "핀홀은 지름 0.5mm 이하의 둥근 반점")을 AI가 자동으로 읽어서
   수치 규칙으로 변환하는 것은 일반적으로 불가능합니다 (자연어를 이미지 처리 규칙으로
   자동 변환하는 것은 신뢰도가 낮고 오판정 위험이 큽니다). 그래서 이 프로그램은:
   - 텍스트 정의 → **사람이 참고하는 기준 문서**로 저장 (백업에도 함께 포함됩니다)
   - 실제 자동 판정 → **작업자가 직접 라벨링한 이미지로 학습한 AI 모델**이 수행
   이렇게 역할을 나눴습니다. 이 방식이 실제로 안정적으로 동작하는 현실적인 구조입니다.

3. 처음 학습에는 **각 유형별로 최소 5~10장 이상**의 이미지를 라벨링하시는 것을 권장합니다
   (너무 적으면 정확도가 낮습니다). 이후 자동판정 → 오판정 수정 → 재학습을 반복하면
   점점 정확도가 올라갑니다 (지속 학습 구조).

---

## 2. EXE 만들기 (Python 설치 없이, GitHub이 대신 빌드)

컴퓨터에는 아무것도 설치하지 않고, 웹사이트에서 클릭만으로 exe를 만드는 방법입니다.
전체 과정은 10분 이내로 걸립니다.

### 2-1. GitHub 무료 계정 만들기
1. https://github.com/signup 접속 → 이메일/비밀번호 입력하여 무료 가입 (신용카드 불필요)

### 2-2. 새 저장소(Repository) 만들기
1. 로그인 후 오른쪽 위 **"+"** 버튼 → **"New repository"** 클릭
2. Repository name에 `defect-inspector` 입력 → **Public** 선택 → **Create repository** 클릭

### 2-3. 이 프로그램 파일 업로드
1. 방금 만든 저장소 화면에서 **"uploading an existing file"** 링크 클릭
   (또는 상단 **Add file → Upload files**)
2. 이 zip 압축을 풀어서 나온 `defect_inspector` 폴더 **안의 모든 파일/폴더**
   (`app.py`, `feature_extractor.py`, `model_manager.py`, `data_store.py`,
   `requirements.txt`, `.github` 폴더 등)를 통째로 화면에 끌어다 놓습니다(드래그 앤 드롭).
   - ⚠️ `defect_inspector` 폴더 자체가 아니라 그 **안의 내용물**을 올려야 합니다.
   - `.github` 폴더도 반드시 포함되어야 자동 빌드가 실행됩니다
     (탐색기에서 숨김 폴더 표시가 필요할 수 있습니다: 파일 탐색기 → 보기 → "숨김 항목" 체크)
3. 아래쪽 **"Commit changes"** 버튼 클릭 (녹색 버튼)

### 2-4. 자동 빌드 확인 및 exe 다운로드
1. 업로드가 끝나면 저장소 상단 메뉴에서 **"Actions"** 탭 클릭
2. `Build Windows EXE`라는 작업이 자동으로 시작되어 있을 것입니다.
   - 노란 점(●) = 빌드 진행 중 (2~4분 정도 소요)
   - 초록 체크(✔) = 빌드 성공
3. 빌드가 끝난 작업(맨 위 항목)을 클릭 → 페이지 아래쪽 **"Artifacts"** 항목에서
   **"DefectInspector-windows"** 를 클릭하면 zip 파일이 다운로드됩니다.
4. 다운로드한 zip을 풀면 그 안에 **`DefectInspector.exe`** 파일이 있습니다.
   이 exe 파일을 원하는 작업용 PC로 복사해서 사용하면 됩니다.
   (이 PC에도 Python 설치가 전혀 필요 없습니다 - exe 하나로 바로 실행됩니다)

이후 프로그램을 수정하고 싶을 때도, 파일을 다시 GitHub에 업로드(Commit)만 하면
자동으로 새 exe가 다시 만들어집니다.

### (참고) 만약 Python 설치가 부담스럽지 않다면
직접 내 PC에서 빌드하고 싶으신 경우를 위해 `build_exe.bat` 스크립트도 함께
포함되어 있습니다. Python 3.10~3.12 설치 후 그 파일을 더블클릭하면 동일한 exe가
로컬에서도 생성됩니다. (2번 방법을 쓰시면 이 과정은 생략하셔도 됩니다)

## 3. 사용 방법


### 화면 구성
- **상단 버튼줄**: 이미지 폴더/파일 불러오기, AI 학습하기, 자동 판정, 데이터 저장/백업
- **판정 유형 관리**: 새 유형 추가(텍스트 입력), 선택한 이미지에 유형 일괄 적용
- **불량 유형 정의**: 유형별 정의를 붙여넣고 저장하는 텍스트창 (참고 문서용)
- **이미지 목록 표**: 선택(체크) / 썸네일 / 파일명 / 자동판정값 / AI 신뢰율(%) / 작업자 판정값

### 작업 순서 (최초)
1. **이미지 폴더/파일 불러오기**로 검사 대상 이미지를 불러옵니다. (모든 이미지 형식 지원:
   jpg, jpeg, png, bmp, gif, tif/tiff, webp 등)
2. **불량 유형 정의** 텍스트창에 각 유형(K 유기, K 갈림, NK 유기, 핀홀 등)의 정의를
   붙여넣고 "정의 저장"을 누릅니다. (필요시 "새 유형 추가"로 유형을 더 등록할 수 있습니다)
3. 이미지들을 보면서 체크박스로 여러 장을 선택 → 상단 "선택한 이미지 일괄 판정값"에서
   유형을 고르고 "선택 항목에 적용"을 누르면, 체크된 이미지 전체의 **작업자 판정값**이
   한번에 채워집니다. (한 장씩은 표의 개별 콤보박스에서 직접 선택도 가능)
4. 각 유형별로 어느 정도 라벨링이 끝나면 **"AI 학습하기"**를 클릭합니다.
   - 라벨링한 이미지는 자동으로 `data/labeled_images/유형명/` 폴더에 누적 보관되고,
     다음 학습부터는 이 누적 데이터까지 함께 사용되어 갈수록 똑똑해집니다.
5. 학습이 끝나면 새 이미지를 불러온 뒤 **"자동 판정"**을 누르면 각 이미지의
   **자동판정값**과 **AI 신뢰율(%)**이 채워집니다.
6. 작업자가 자동판정 결과를 검수하면서 틀린 항목은 "작업자 판정값"으로 정정 →
   다시 "AI 학습하기"를 눌러 재학습하면 정확도가 점점 향상됩니다.
7. **"데이터 저장/백업"**을 눌러 원하는 위치(예: 외장하드, 공유폴더)에
   모델과 데이터 전체를 타임스탬프 폴더로 복사 백업할 수 있습니다.

### 데이터/모델 저장 위치
exe 파일과 같은 폴더에 아래와 같이 자동 생성됩니다.
```
DefectInspector.exe
data/
  categories.json      (판정 유형 목록)
  rules.json            (유형별 정의 텍스트)
  dataset.csv            (누적 학습 데이터 목록)
  labeled_images/유형명/  (학습에 사용된 이미지 사본)
model/
  classifier.pkl          (학습된 AI 모델)
  meta.json               (학습 일시, 정확도 등 정보)
```
이 두 폴더(`data`, `model`)만 백업/복사하면 다른 PC에서도 그대로 이어서 사용할 수 있습니다.

## 4. 직접 개발환경에서 실행(테스트)하고 싶다면

```bash
pip install -r requirements.txt
python app.py
```
(Windows에는 Python 표준 설치에 `tkinter`가 기본 포함되어 있어 별도 설치가 필요 없습니다.)

---

## 5. 폴더/파일 구성

```
defect_inspector/
  app.py                 메인 GUI 프로그램
  feature_extractor.py   이미지 → 특징 벡터 추출 (색상/형태/질감)
  model_manager.py        AI 모델 학습/저장/예측 (RandomForest)
  data_store.py            유형/정의/데이터셋 저장·백업 관리
  requirements.txt        필요 라이브러리 목록
  build_exe.bat            Windows용 EXE 빌드 스크립트 (내 PC에서 직접 빌드할 경우)
  .github/workflows/build.yml   GitHub이 대신 exe를 빌드해주는 자동화 설정
  README.md                본 설명서
```

## 6. 향후 커스터마이징 아이디어
- 판정 유형이 많아지고(10종 이상) 데이터가 충분히 쌓이면 RandomForest 대신
  딥러닝(CNN) 기반으로 교체하면 더 높은 정확도를 기대할 수 있습니다.
- 자동 판정 신뢰율이 낮은(예: 70% 미만) 이미지만 따로 모아 작업자가 우선 검수하도록
  표를 정렬/필터링하는 기능을 추가할 수 있습니다.
- 네트워크 폴더(NAS)를 `data/` 경로로 지정하면 여러 PC가 같은 학습 데이터를 공유하도록
  확장할 수도 있습니다.
